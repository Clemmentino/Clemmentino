### About

I'm a 2nd-year BSIT student based in Panabo City, building interfaces that feel clean, direct, and grounded in real use. Frontend is where I'm strongest — layout, spacing, readability, responsive behavior — but I also handle the backend connections that make a project work end to end.

My best work sits between design and function: dashboards, monitoring tools, and public-interest systems that need to be understood quickly. Photography and videography shape how I look at composition, which carries into how I build.
